# Company artwork

These files identify the corresponding services. They are bundled with the UI;
rendering a logo never requests an external asset. Marks retain their original
colors and aspect ratios. Functional interface icons remain separate.

Sources checked on September 5, 2026:

Added September 9, 2026: EA, Ubisoft, Battle.net, Rockstar Games, itch.io,
Paradox Interactive, and YouTube Music use the corresponding SVGs from
[Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons).
Amazon uses the 14.0.0 `amazon.svg`; Xbox and Microsoft Store use the 11.0.0
`xbox.svg` and `microsoftstore.svg`. Simple Icons distributes its icon paths
under CC0; these monochrome marks display in white on Exo's dark background.
Wargaming uses its [site favicon](https://wargaming.com/assets/img/favicon.ico).
