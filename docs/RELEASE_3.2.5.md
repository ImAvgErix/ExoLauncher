# Exo Launcher 3.2.5

Setup can install the hosted apps you want, Exo updates on the boot mark, and the mini player no longer jumps to full volume.

- **Install Discord, Spotify, Apple Music and Cider during setup.** Permissions lists each app. You can install Spotify and Cider together even if Exo plays another service.
- **Updates before the library.** If a newer Exo is on GitHub, the logo screen offers it. Update installs there; the installer closes this build and opens the new one.
- **Mini player volume stays where you left it.** Clicking the control no longer writes 100% onto a quieter song.

[Download Exo Launcher for Windows 11](https://github.com/ImAvgErix/ExoLauncher/releases/download/v3.2.5/ExoLauncher-Setup.exe)

Requires Windows 11 x64.
