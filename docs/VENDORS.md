# Game store support

Exo brings games together while each store handles its own accounts, purchases, and downloads.

| Store | What Exo can do |
| --- | --- |
| Steam | Show your library and provide supported Play, Install, Update, and Remove actions through Steam. |
| Epic Games | Show your library and provide supported game actions using Legendary. |
| GOG | Show available library information and provide supported game actions using gogdl. |
| Riot | Find installed games and use the official client to launch or update supported titles. |
| Xbox, EA, Ubisoft, Battle.net, Amazon, and Rockstar | Find and launch games already installed on your PC. Full account libraries and download controls aren't supported here. |
| Local games | Add a game folder yourself and choose what to launch. |

## Connecting a store

Open Settings to connect the store you want to use. Keep the official client installed where the store requires it, and sign in with the account that owns your games.

Epic and GOG use separate helper tools: [Legendary](https://github.com/derrod/legendary) and [gogdl](https://github.com/Heroic-Games-Launcher/heroic-gogdl). Exo will show a message if a required tool or sign-in is missing. The tools have their own setup instructions and licenses.

## If a game or action is missing

- Check that you're signed in to the right store account.
- Check that the game is installed if its store only supports finding local games.
- Refresh your library after installing or removing a game.
- Read any message Exo shows when a store connection or helper needs attention.

The actions shown depend on the store, the game, and your account. Exo doesn't replace store ownership requirements, copy protection, or anti-cheat software.
