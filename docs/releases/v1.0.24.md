# Exo Launcher 1.0.24

**Choose the exact copy. Launch the exact game. Let the achievement moment belong to Exo.**

Version 1.0.24 is the reliability and finish pass for Exo's unified Windows game library. It tightens store routing, account isolation, achievement attribution, official-client honesty, notification presentation, and the everyday feel of the dashboard.

## Highlights

- **One card, every real source.** Exact same-title copies can share a card without merging their store IDs, ownership, update state, playtime, or actions. Choose the source you want in game details.
- **Exact install and update routing.** Steam actions target the selected app ID; Epic cold launches wait briefly for the official command listener before sending the selected game URI.
- **Account-safe state.** Steam and Epic caches are isolated by active account. Machine-wide installs remain visible when useful, but unknown identity never becomes a fake ownership claim.
- **Achievement notifications tied to a real Exo session.** A baseline is taken before handoff and activated only when the selected game launches successfully. Manual refreshes and failed launches remain silent.
- **A distinct Exo reward moment.** The native 432×122 plate uses real provider art when available, Bronze/Silver/Gold/Platinum accents, directional motion, nine exact screen anchors, a fixed 3.5-second display, and an original 1.18-second futuristic stereo cue.
- **Broader official-client support without pretending.** Xbox, EA app, Ubisoft Connect, Battle.net, Amazon Games, and Rockstar Games Launcher now report Installed/Not installed honestly and can be opened from Settings. Unsupported libraries and per-game actions stay absent.
- **Sharper, calmer UI.** Pure AMOLED surfaces, compact Settings, restored card lift, high-resolution cover upgrades, clear launcher wording, visible update badges, and pinned rows that stay contained.
- **Less idle work.** Quiet mode performs no Core Audio enumeration while Exo is idle, then returns to its fast active cadence only during a real Exo-driven operation.
- **Cleaner atomic updates.** WebView2 state now lives in Exo's stable local-data area, and setup waits only for Exo-owned browser children before removing the replaced app tree.

The full history is in the [changelog](https://github.com/ImAvgErix/ExoLauncher/blob/main/CHANGELOG.md).

## Install

Download **ExoLauncher-Setup.exe** below and run it on Windows 11 x64. Exo installs per-user under `%LOCALAPPDATA%\ExoLauncher\app`.

The installer is currently **not code-signed**, so Windows SmartScreen may ask for confirmation. The SHA-256 digest for this build is:

```text
3A0B7D7033C71500D086DBB900BF12E52BC206F637B5BB2DE009DAE6219D518D
```

## Honest boundaries

- Achievement reading and Exo unlock notifications currently cover supported Steam and Epic provider data; an unavailable or contradictory provider result is shown as unknown, not zero.
- Exo can suppress supported client windows and client audio only during Exo-driven operations. Vendor overlays, chat, game-owned UI, and Windows notification policy remain under their owners' control.
- The added Xbox, EA, Ubisoft, Battle.net, Amazon, and Rockstar integrations detect/open the official client only; they do not yet expose those libraries through Exo.

If something is wrong, [report it with the game, store, and expected source](https://github.com/ImAvgErix/ExoLauncher/issues).
