# Exo Launcher 2.0.1

**The 2.0 library people actually hit.**

Install, update, and play from Exo. Steam, Epic, GOG, and Riot remain the backends. Their windows stay hidden. Progress lives in Exo.

## This release

- **Minecraft / Roblox posters** — official Microsoft Store catalog art, then Steam title match or the installed icon.
- **Epic / Riot times** — last launched matches Legendary/EGL ids and titles; Riot product aliases are accepted.
- **Exo friends** — profiles open on the reserved handle; avatars survive chunked downloads; the roster picture stays if profile media is still loading.
- **Unavailable** — installed titles whose Steam ownership is still unverified stay **Play**. Refunded titles stay **Buy again**.
- **2.0 upgrade** — 1.x installs now get Exo account setup instead of skipping it. The library still works if you skip.
- **Download percent** — live byte counts reach the UI.
- **Achievement preview** — no longer restarts mid-hold.

Windows 11 x64. Per-user install under `%LOCALAPPDATA%\ExoLauncher\app`.

Google sign-in and email magic links are not enabled. Email/password accounts are live.

The installer is not code-signed. Verify the SHA-256 digest on the asset if you want an independent check.
