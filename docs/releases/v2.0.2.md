# Exo Launcher 2.0.2

**Issue #13: Roblox posters, Epic hours, home avatar, and the signed-in onboarding flash.**

## This release

- Epic hours apply on the library scan, not only a later refresh.
- Roblox and Minecraft posters come from the Microsoft Store catalog, not a Steam title match.
- The home chip shows the uploaded picture or the game chosen as avatar.
- A signed-in 2.0 install no longer flashes account setup.
- Exo friend rows stay open when clicked. Last-played survives a small Epic/Riot clock skew.

Windows 11 x64. Per-user install under `%LOCALAPPDATA%\ExoLauncher\app`.

The installer is not code-signed. Verify the SHA-256 digest on the asset if you want an independent check.
