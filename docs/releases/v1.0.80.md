# Exo Launcher 1.0.80

**Public beta chrome. Settings stop listing missing stores.**

Titlebar is the mark, search, settings, and window buttons. Play lives on the selected game. Settings only lists store apps that are actually on the PC.

## This release

- **Chrome** — no Exo/Launcher wordmark, no Play or Apply in the titlebar. Play stays on the Now plate and the game page.
- **Settings** — store rows are client-present or signed-in only. Bundled Legendary or gogdl does not invent a missing Epic or GOG row.
- **First-run / empty** — Open library or Add a folder. Empty copy is "Nothing here yet". No owner-specific titles. No ghost store list.

Windows 11 x64. Per-user install under `%LOCALAPPDATA%\ExoLauncher\app`.
