# Exo Launcher 1.0.79

**One home. The other clients stay out of the way.**

Install, update, and play from Exo. Steam, Epic, GOG, and Riot remain the backends. Their windows stay hidden. Progress lives in Exo.

## This release

- **Now plate** — one featured game (downloading, playing, update, or last launched). Not a carousel.
- **Game page** — open a library or pinned tile; Close details fades. Home does not jump or flash.
- **Steam** — install, update, and uninstall through `ExoLauncher.SteamIpc` (`steamclient64.dll`). Not OCR, not clicks, not DepotDownloader.
- **Install percent** — live Steam job when bytes are moving; indeterminate until then. Leftover ACF totals are not shown as 0% or 100%.
- **Stores** — Epic Legendary, GOG gogdl, Riot official patch API. Xbox / EA / Ubisoft / Battle.net / Amazon / Rockstar: list and launch only.
- **Mark** — the italic three-bar E. Idle is the original E; the bars move only while Exo is busy.

Windows 11 x64. Per-user install under `%LOCALAPPDATA%\ExoLauncher\app`.

The installer is not code-signed. Verify the SHA-256 digest on the asset if you want an independent check.
