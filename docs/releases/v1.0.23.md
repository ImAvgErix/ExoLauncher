# Exo Launcher 1.0.23

**One library. Quieter stores. Achievement moments that belong to Exo.**

This is the largest Exo Launcher checkpoint since the first public build. It brings the recent launcher, game-control, search, playtime, achievement, privacy, reliability, and performance work together in one Windows installer.

## Highlights

- **One exact action per game.** Play, install, update, cancel, uninstall, or safely stop the selected title without treating a different queued game as the target.
- **Smarter discovery.** Search tolerates misspellings, punctuation changes, word-order differences, and accidental sequel-number mismatches.
- **Quieter sessions.** Exo keeps supported store windows and store audio in the background while protecting games, overlays, services, and anti-cheat.
- **Better achievement delivery.** Steam and Epic unlocks can use real provider art, provider-aware Bronze/Silver/Gold/Platinum presentation, exact screen anchors, and a compact CC0 reward cue.
- **Restart-safe notifications.** Confirmed unlock transitions are persisted before presentation, acknowledged only after the native window opens, and replayed only for the matching provider source and account.
- **Honest store state.** Official Epic and GOG client presence is now distinct from optional Legendary/gogdl availability, so a bundled helper cannot make an absent client look installed.
- **Local-first Launcher.** Exo account, profile, profile-sync, and Launcher cloud-sync paths have been removed. Store identity remains with each store; social identity remains with Exo Link.
- **Faster first paint.** Cover networking is deferred and bounded, Epic remote playtime is off the startup critical path, and unchanged derived state no longer forces redundant refreshes.

The full history is in the [changelog](https://github.com/ImAvgErix/ExoLauncher/blob/main/CHANGELOG.md).

## Install

Download **ExoLauncher-Setup.exe** below and run it on Windows 11 x64. Exo installs per-user under `%LOCALAPPDATA%\ExoLauncher\app`.

The installer is currently **not code-signed**, so Windows SmartScreen may ask for confirmation. GitHub publishes the asset's SHA-256 digest; the expected digest for this build is:

```text
A6F34B1B322E29853EE84434F706BB1ED8C938A0740DF123D71C4C8E9E401DD3
```

## Known boundaries in this checkpoint

- Achievement reading and Exo unlock notifications currently cover Steam and Epic provider data.
- Vendor/game overlays, chat popups, and Windows notifications remain controlled by those systems; Exo's quiet mode controls supported store chrome and store audio on a best-effort basis.
- Notification visual refinement, provider-specific achievement edge cases, multi-account/multi-store duplicate handling, and expanded official backend coverage continue in the next pass.

If something is wrong, [report it with the game and store name](https://github.com/ImAvgErix/ExoLauncher/issues).
